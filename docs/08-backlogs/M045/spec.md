## Scope

Deliver PRD D-23 as one end-to-end increment on the completed M044/M039 foundations: Translator `/translate`, Write `/rewrite`, independent collapsible navigation/toolbar, screenshot-derived composition/tokens, conservative mobile reflow, the three permitted toolbar settings, copy/swap/reuse, local change review, native result editing and on-demand sentence alternatives. Include the API, shared AI, admission/settlement/status and generated-client changes indispensable to the new Write journey.

Selected product scope: FR-003–023 (excluding retired FR-015), FR-024–030, FR-032–039; NFR-001–007 only their applicable assertions; D-21/D-22 preserved. Selected UX scenarios and owner sections are mapped below. Existing authentication, 5,000/2,000 source limits, one-second pause, no storage/history, ordered usage and stale-response rules remain regression requirements. Automatic detection must become visible and supply a trustworthy resolved language for swap/alternatives; the current full-text success DTOs do not expose that value yet.

Exclude document upload/drag-drop advertising, word synonyms, DeepL branding, premium/customization controls, hidden previous-style restoration, targeted sentence identity preservation through manual edits, custom language pickers/modal mobile sheets, Google/email reactivation, routing administration, combined translation/restyling, unrelated auth redesign, production deployment, full-corpus qualification and live percentile benchmarking. Exclusion from this milestone never marks a product release gate passed. No new submit/reset/usage/counter/status UI.

## Constraints and decisions

Required checks run unattended. Source text is data, never an instruction to execute; synthetic fixtures replace the screenshot's personal account information. Screenshots are documented in UX §2; their Desktop files are not required for automated builds. No new library or service is required by this plan. Preserve authentication/antiforgery and real migrations; do not fabricate a test auth/provider success in production.

Technical choices are fixed at their shared owners: [API §2.2](../../05-api-design.md#22-m045-selected-alternatives-contract), [AI §5.4](../../04-llm-specification.md#54-context-and-monetary-bounds), [UX §8.4](../../02-ux-specification.md#84-m045-sentence-and-comparison-boundaries) and the [evaluation extension](../../verification/llm-evaluation.md#d-23-sentence-alternatives-evidence-extension). C# metadata remains the future wire-shape authority; no handwritten schema is part of planning.

Local tools observed: Node 24.20.0, npm 11.11.0, .NET SDK 10.0.302, installed frontend dependencies and Playwright Chromium revision 1243 cache. No provider credentials were read and no paid call was made. AC-013 requires actual credential/profile/budget availability before its task. The prior $0.05 serving ceiling remains a per-operation restriction, not a new whole-run spending authorization. Continue independent implementation if that gate is unavailable; M045 cannot be Done with AC-013 unverified. Production qualification/startup and full release gates remain governed by #4/#6, not waived by this package.
